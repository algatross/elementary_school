## 一、项目定位

面向二年级上册（人教版 2025 秋版）的辅助学习静态网站，纯 HTML 单文件架构，无需登录、双击即用、GitHub Pages 免费托管。孩子练习的数据（打卡日历、成绩）保存在各自设备的浏览器 localStorage 中，不上传服务器。

设计风格统一采用 **Daisy Days 贴纸绘本风**（奶油纸底 + 粗描边 + 错位硬阴影 + Fredoka One 圆体 + 手绘雏菊/星星/彩虹 SVG 装饰）。

## 四、已完成情况

### ✅ 数学 · 口算打卡（math/koucalc.html）
- 四种题型 + 综合挑战：20以内加减（偏进位/退位）、100以内加减、1~6表内乘法、乘加乘减
- 自动出题 + 自动批改：答对即时鼓励（连对5题专属表扬），错1次"再想一想"、错2次公布答案
- 计时（超"每分钟8题"达标线变橙提醒）、星级评价、达标勋章、彩带庆祝、错题回顾
- **难度已按要求调整**：100以内加减 = 55% 两位数+两位数（必进位、和≤99）+ 35% 两位数−两位数（必借位、差≥10）+ 10% 两位数±一位数调节
- 出题逻辑经 node 10万+5万题两轮校验：答案全对、两位数对两位数题 100% 含进位/借位、结果均 10~99
- 打卡日历：整月视图、◀▶切月，薄荷绿=当天全对、奶油黄=打卡有错

### ✅ 主页 · 学习大厅（index.html）
- 学科四宫格导航：🧮数学（口算）、📖语文（已点亮）、🔤英语（预留）、🎨更多（预留）
- 连续打卡横幅 + 全对打卡日历（与口算页读同一份记录 `koucalc_checkin_v1`）

### ✅ 语文 · 语文小课堂（chinese/yuwen.html）
- **课文模块**：27 课（含 4 节识字课）按单元分组，每课含 📌摘要 + 💡解析（中心思想/写法亮点）+ 🔊原文朗读（TTS）+ 会认字 395 个/会写字 230 个/词语 221 个（点击发音）
- **生字卡模块**：翻卡记忆，显示拼音+组词，按课筛选、乱序、点击发音
- **古诗模块**：4 首必背（登鹳雀楼/望庐山瀑布/江雪/敕勒歌），单句/整首/慢速朗读
- **答题模块**：每课 2 道手工编写的课文理解题（共 54 道）+ 自动生成"选读音"拼音题，答错带解析，结束出星级并存打卡记录 `yuwen_checkin_v1`
- 数据全部由脚本从课本 PDF 提取：拼音用 pypinyin 重新生成（课本内嵌拼音为防复制字体）；识字/写字/词语表按课精确归组（已修复印刷页码伪装课号、课号与首字同行、课文末页生字标注混入等解析坑）
